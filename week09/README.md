# 9-апта. Камера моделі және LookAt

Сахнада 8-аптадағы бес айналатын куб бар. Камераның бастапқы орны — (0, 0, 3), қарау бағыты — (0, 0, −1).

## Құрастыру және іске қосу

Репозиторий түбірінен Windows-та CMake және MinGW арқылы:

```powershell
cmake -S week09 -B week09/build -G "MinGW Makefiles"
cmake --build week09/build
.\week09\build\week09.exe
```

Алғашқы құрастыруда CMake GLM кітапханасын жүктейді.

## Басқару

| Перне | Әрекет |
| --- | --- |
| W / S | Алға / артқа |
| A / D | Солға / оңға |
| Space / Left Shift | Жоғары / төмен |
| Left Ctrl (басып тұру) | Қозғалыс жылдамдығын екі есе арттыру |
| 1 / 2 | Еркін камера / координат басына қарау |
| R | Бастапқы орынға қайту |
| Esc | Шығу |

## Тапсырмалар

1. **LookAt нұсқаларын салыстыру.** R, содан кейін 2 пернесін басып, A немесе D арқылы бүйірге жылжы. Мақсат (0, 0, 0) болғандықтан, камера координат басына қарай бұрылады. R және 1 пернелерінен кейін сол әрекетті қайтала. Мақсат нүктесі `camPos + camFront` болғанда, A камераны солға жылжытады және қарау бағыты −Z бойымен сақталады. Нысанды әр қырынан қарайтын модель редакторында нысанаға бекітілген камера ыңғайлы.
2. **Тік қозғалыс.** Space және Left Shift камераны `camUp = (0, 1, 0)` бойымен жылжытады. Бұл сахнада ол әлемнің Y осімен бағыттас, сондықтан камера көлденең бағдарын сақтай отырып көтеріледі немесе төмендейді.
3. **Жылдамдық.** Қалыпты жылдамдық секундына 2,5 бірлік, Left Ctrl басулы кезде 5 бірлік. Әр кадрдағы орын ауыстыру `dt` арқылы есептеледі. Екіге көбейту `dt`-ге дейін немесе кейін орындалса, математикалық нәтиже бірдей.
