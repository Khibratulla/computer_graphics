# 10-апта. Еркін камера

Сахнада 9-аптадағы бес айналатын куб бар. Камера (0, 0, 3) нүктесінен −Z бағытына қарайды. Бастапқы бұрыштар: yaw −90°, pitch 0°, FOV 45°.

## Құрастыру және іске қосу

Репозиторий түбірінен Windows-та CMake және Visual Studio C++ (x64) арқылы:

```powershell
cmake -S week10 -B week10/build -A x64
cmake --build week10/build --config Release
.\week10\build\Release\week10.exe
```

MinGW-w64 (x64) қолданылса, бөлек бумада құрастыр:

```powershell
cmake -S week10 -B week10/build/mingw -G "MinGW Makefiles"
cmake --build week10/build/mingw
.\week10\build\mingw\week10.exe
```

Алғашқы құрастыруда CMake GLM 1.0.1 кітапханасын жүктейді.

## Тапсырмаларды тексеру

1. **Pitch шегі.** ±89° шегін уақытша алып тастаған тексеру нұсқасында pitch дәл **+90°** болғанда кадрда тек фон қалды. Тексеру кезінде камера (0.25, 0, 3) нүктесіне қойылды. Теорияда `cos(90°) = 0`, сондықтан қарау бағыты `camUp = (0, 1, 0)` векторымен бағыттас болады. Тексеруде `camPos + camFront` қосындысын дөңгелектегенде X пен Z бойынша өте кіші ауытқулар жоғалды. `glm::lookAt` ішіндегі векторлық көбейтінді нөл болып, оны нормалау кезінде `NaN` шықты. Тапсырылатын нұсқада ±89° шегі қосулы.
2. **Сезімталдық.** Тінтуір callback-іне басқарылатын көлденең ығысулар беріп, үш мәнді тексердім. Толық айналымға 0.03 кезінде 12 000, 0.1 кезінде 3 600, ал 0.5 кезінде 720 курсор бірлігі керек болды. **0.1** мәнін қалдырдым, себебі ол ұсақ бұрылыстарды басқаруға мүмкіндік береді және толық айналымда 0.03-тен аз қозғалыс қажет етеді. Тінтуірді көтеру саны қолжетімді жүріске тәуелді. `constexpr` бұл коэффициенттің орындалу кезінде тұрақты екенін білдіреді. Пернемен өзгерту үшін оны өзгеретін айнымалыға ауыстыруға болады.
3. **Invert Y.** I тек `GLFW_PRESS` оқиғасында ауысады. `GLFW_REPEAT` оқиғалары ескерілмейді, сондықтан перне басулы тұрғанда баптау қайта-қайта өзгермейді. WASD керісінше перне басулы тұрған әр кадрда `dt`-ға сай орын ауыстырады.
4. **Камера күйі.** P бір басылғанда `camPos`, `camFront`, yaw, pitch, FOV және бағыт векторының ұзындығы шығады. Тригонометриялық формула дәл арифметикада бірлік вектор береді. `float` дөңгелектеуінен ұзындық 1-ден аздап ауытқуы мүмкін. `normalize` оны 1-ге жақындатады, бірақ дөңгелектеу қалуы мүмкін.
5. **Кең FOV.** 90° кезінде көрінетін аймақ ұлғайып, ортадағы куб кадрда кішірейеді. Перспективалық проекцияда экрандағы координаттар тереңдікке бөлінеді, ал масштаб `1 / tan(FOV / 2)` арқылы өзгереді. Кең бұрышта кадр шетіне жақын нысандардың бұрыштық өлшемдері жазық экранда біркелкі берілмейді, сондықтан қырлары созылыңқы көрінуі мүмкін. Бұл перспективаның қалыпты қасиеті.

## Қосымша тапсырмалар

- Shift басулы кезде қозғалыс жылдамдығы 2.5-тен 5 бірлік/с-қа өседі.
- Терезе тақырыбында yaw, pitch, FOV және Invert Y күйі көрінеді.
- R камераны толық бастапқы күйіне қайтарады. Invert Y баптауы сақталады.
- Yaw толық айналым сайын 360° бойынша оралады. Шек екі бұрылу бағытында тексерілді.
