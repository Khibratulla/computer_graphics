# 12-апта. Бірнеше текстура

11-аптадағы бес айналатын кубқа екі текстура қосылды: ағаш жәшік және мөлдір фоны бар логотип. Бастапқы режим — сызықтық араластыру, `blend = 0.5`.

## Іске қосу

`week12/run.bat` файлын екі рет бас. Скрипт CMake арқылы Release нұсқасын құрастырып, ашады. Visual Studio C++ x64 және CMake қажет. Алғашқы құрастыруда GLM 1.0.1 интернеттен жүктеледі.

Репозиторий түбірінен:

```powershell
cmake -S week12 -B week12/build -A x64
cmake --build week12/build --config Release
.\week12\build\Release\week12.exe
```

Бағдарлама құрастырылған соң `week12/build/Release/week12.exe` арқылы да іске қосылады. CMake суреттерге абсолют жол береді, сондықтан жұмыс бумасы маңызды емес. Жобаны басқа жерге көшіргенде жаңадан құрастыр.

## Басқару

| Перне немесе әрекет | Нәтиже |
| --- | --- |
| ↑ / ↓ | blend мәнін өсіру / азайту, секундына 0.5 |
| 1 | Сызықтық араластыру: mix(base, decal, blend) |
| 2 | Көбейту: base * decal |
| 3 | Қосу: clamp(base + decal, 0, 1) |
| 4 | Логотипті альфамен жапсыру: mix(base, decal, decal.a) |
| 5 | Төменнен жоғары ауысу: mix(base, decal, vTexCoord.y) |
| Тінтуір | Камераның қарау бағыты |
| Дөңгелек | FOV 1–90 градус |
| WASD | Қозғалу |
| Space / C | Жоғары / төмен |
| Shift немесе Left Ctrl | Екі есе жылдамдық |
| I | Invert Y |
| P | Камера күйін терминалға шығару |
| R | Камераны бастапқы күйге қайтару |
| Esc | Шығу |

↑/↓ басулы тұрғанда `blend` үздіксіз өзгереді және 0..1 аралығына шектеледі. Бұл коэффициент 1-режимде пайдаланылады. 2–5 режимдері PDF-тағы өз формулаларымен жұмыс істейді. Терезе тақырыбы режим мен blend мәнін көрсетеді. Режим пернелері GLFW_PRESS кезінде ғана орындалады.

## Іске асыру

- Вершиналар, UV, вершина шейдері және `loadTexture()` 11-аптадағы күйінде қалды.
- Екі рет loadTexture шақырылады: `container.png` — RGB, `logo.png` — RGBA, екеуі де 512×512.
- `glUseProgram` шақырылғаннан кейін sampler2D `texture1` үшін 0, `texture2` үшін 1 нөмірі бір рет жазылады. Бұл сандар текстура ID-лері емес, текстуралық бірліктер.
- Әр кадрда GL_TEXTURE0 → tex1, GL_TEXTURE1 → tex2 байланады; blend glUniform1f арқылы беріледі.
- Бастапқы blend=0.5. ↑/↓ өзгерісі dt-ға көбейтіледі; шектеу std::clamp арқылы орындалады.
- Фрагмент шейдері екі текстураны texture() арқылы оқып, таңдалған режимді қолданады.
- Екі текстурада да GL_REPEAT, GL_LINEAR_MIPMAP_LINEAR және GL_LINEAR сақталған. Mipmap дерек жүктелгеннен кейін жасалады.
- Камера, MVP, depth test және CCW back-face culling сақталған. Екі текстура да аяқталғанда босатылады.
- Терминал фрагмент шейдеріне қолжетімді текстуралық бірліктер санын көрсетеді.

`mix(a,b,t) = a*(1-t) + b*t`: t=0 кезінде бірінші, t=1 кезінде екінші сурет қалады. Альфа режимінде t әр пиксельдің decal.a мәнінен алынады: мөлдір фон ағашты сақтайды, логотиптің өзі оның үстіне салынады. Сызықтық режим бүкіл RGBA векторын тұрақты blend бойынша араластырады.

## Тексеру нәтижелері

- MSVC x64 Release құрастыруы сәтті аяқталды.
- Жасырын OpenGL терезесінде бірдей камера және айналу бұрышымен жеті кадр алынды; OpenGL қатесі болған жоқ.
- Нақты processInput функциясы 30 және 144 FPS кезінде бір секундта blend=0.5 бергені тексерілді. Екі шегі және режим пернелері де тексерілді.
- GPU uniform мәндері sampler1=0, sampler2=1 екенін растады.
- Кадрлардағы RGB пиксельдері формулалармен салыстырылды: сызықтық араластыру мен қосуда ең үлкен айырма 1/255, көбейтуде 1.32/255 болды (сүзгілеу және дөңгелектеу).
- RGBA кадрынан логотиптің альфасы нөл болатын 68 683 пиксель табылды: альфа режимінде сол жерде ағаш түсі сақталғаны тексерілді.
- Вершина шейдері, vertices/UV және loadTexture мәтіні 11-аптамен бірдей екені салыстырылды.

Тексеру нұсқасы жұмыс бумасында бөлек жасалды; тапсырылатын main.cpp қалыпты интерактивті бағдарлама болып қалды.
